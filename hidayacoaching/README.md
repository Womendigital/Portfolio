Plateforme de Coaching

Description
Application web de coaching permettant :
- Inscription et authentification sécurisée des utilisateurs
- Dashboard pour suivre les inscrits
- Gestion complète des profils utilisateurs
- Récupération de mot de passe

 Intégration du paiement en ligne simulée :
- Les clés API utilisées sont fictives pour démonstration uniquement
- Le projet peut être facilement connecté à un vrai service de paiement
