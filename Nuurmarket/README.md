NuurMarket — Supermarché en ligne

NuurMarket est une plateforme e‑commerce de supermarché en ligne qui permet aux utilisateurs de parcourir, sélectionner et acheter des produits alimentaires et ménagers depuis leur ordinateur ou leur smartphone. 

Le projet illustre les concepts fondamentaux du e‑commerce, incluant :
- Catalogue de produits avec catégories
- Panier d’achat dynamique
- Gestion des utilisateurs (inscription et authentification)
- Paiement simulé avec fausses clés API
- Interface utilisateur responsive

Certaines fonctionnalités, comme les paiements en ligne et la gestion réelle des stocks, sont simulées pour des raisons de démonstration.
